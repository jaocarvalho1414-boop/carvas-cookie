# 🍪 Carvas Cookies

Site desenvolvido para a Carvas Cookies, um projeto próprio de produção e venda de cookies.

## Sobre o projeto

Criei este site para ter um espaço online para apresentar a marca e os produtos da Carvas Cookies, além de facilitar a divulgação e o contato com clientes.

Foi um projeto em que pude colocar em prática meus conhecimentos de desenvolvimento web e, principalmente, transformar programação em uma solução para uma situação real.

## Tecnologias

- PHP
- HTML
- CSS
- JavaScript

## O que desenvolvi

- Página para apresentação da marca
- Exibição dos produtos
- Estrutura de navegação do site
- Interface adaptada para diferentes dispositivos
- Recursos voltados para divulgação e vendas

## Resultado

O site fez parte do projeto de vendas da Carvas Cookies, que envolveu a produção, divulgação e venda de aproximadamente **420 cookies**, com faturamento médio de **R$ 1.050**.

Além da parte de programação, o projeto me ajudou a desenvolver experiência com organização, comunicação, negociação e aplicação de tecnologia em uma atividade real.
